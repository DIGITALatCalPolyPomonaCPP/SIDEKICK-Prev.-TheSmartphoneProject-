# Inertial measurement unit (IMU)

The source snapshot contains seven chronological KiCad archives for an ICM-20948-based IMU board. Later revisions add dedicated power-supply and level-shifting schematic sheets alongside the main schematic and PCB.

All seven revisions are retained because the source repository presents them as design history and does not explicitly label a production-ready release.

See [PROVENANCE.md](PROVENANCE.md) for origin and licensing status.
