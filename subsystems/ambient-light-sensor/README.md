# Ambient-light sensor

The repository-derived source snapshot contains a KiCad design archive for a VCNL4030X01-based light-sensor board. The archive includes schematic and PCB files, a custom footprint, a STEP model, and chronological KiCad backups.

`source/additional-snapshots/` contains four separately supplied KiCad light-sensor snapshots dated in their filenames from January 22 through February 5, 2026. They are retained as distinct archives so no revision is overwritten or silently selected as final.
