# Real-time clock

This subsystem contains a supplied KiCad archive for an RV-3028-C8 real-time-clock board. The archive includes schematic and PCB source, a custom component symbol/footprint and STEP model, board and schematic renders, PDF/SVG outputs, and a prototype snapshot.

The original archive filename is preserved exactly. Its trailing numeric token is treated as source metadata and is not interpreted as a validated date or time.

See [PROVENANCE.md](PROVENANCE.md) for source and licensing status.
