# STM32 controller

This subsystem contains a supplied engineering archive centered on an STM32G431 controller. It includes:

- KiCad schematic, PCB, and project files;
- component symbols, footprints, STEP/STL models, and import notes;
- power-selection, regulation, USB-protection, connector, and support-component assets; and
- an STM32CubeIDE project with startup code, HAL configuration, and an `FPGA Mock.ioc` configuration.

The original filename—including its spelling—is preserved exactly. See [PROVENANCE.md](PROVENANCE.md) for source and licensing status.
