# Heat sensor

This subsystem contains a supplied KiCad schematic-project archive for a heat-sensing circuit. The archive contains `.kicad_sch`, `.kicad_pro`, and `.kicad_prl` files; no PCB file is present in this snapshot.

The original archive filename is preserved exactly. Its numeric tokens are treated as source metadata and are not interpreted as validated dates or times.
