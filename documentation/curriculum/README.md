# Curriculum and mini-projects

This collection connects the Smartphone Project to DIGITAL's teaching program.

- **Operating Systems Curriculum** (147 slides): memory and virtualization, virtual machines, compiler construction, and operating-system services.
- **The SoC Curriculum — Meeting #1: Abstraction** (17 slides): abstraction, interfaces and implementations, Boolean logic/algebra, logic gates, HDL, and chips/modules.
- **Thermometer Mini-Project** (10 slides): requirements, interface choice, MCP9600 thermocouple interface, and daughterboard design. The title slide credits Russell Chung, Pyson, and Ethan Wong.
- **Fingerprint Sensor Mini-Project** (11 slides): sensor technology and component-selection matrices, FPC2532AP requirements, schematic/footprint work, and daughterboard integration. The title slide credits Anish, Russell, Logan, and Ethan.

The original PowerPoint files are preserved unchanged. See [PROVENANCE.md](PROVENANCE.md) and [SHA256SUMS](SHA256SUMS).
