# Smartphone Project updates

These presentations document the transition from Phase II planning into Phase III subsystem development.

- **Phase II — SMART, Budget, Gantt and Plans for Phase III** (14 slides): goals, integrated schedule, three-milestone budget, team structure, and seven project milestones.
- **Phase III — Hardware Design Project Update 1** (14 slides): motherboard/System-on-Module, haptics, RTC, microphone, heat sensor, STM32 controller, fingerprint sensor, thermometer/barometer, and camera work.
- **Phase III — Thermals & Enclosure Project Update 1** (11 slides): thermal and enclosure constraints, copper-plate heat-spreading approach, three enclosure iterations, and future design plans.

The original PowerPoint files are preserved unchanged. See [PROVENANCE.md](PROVENANCE.md) and [SHA256SUMS](SHA256SUMS).
