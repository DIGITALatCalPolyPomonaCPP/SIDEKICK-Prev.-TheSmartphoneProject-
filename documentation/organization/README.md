# DIGITAL organizational records

- **DIGITAL CPP Project Proposal — MEP**: proposes DIGITAL as a project-based engineering initiative for interdisciplinary systems design and presents the Smartphone Project as its flagship example.
- **DIGITAL CPP Constitution and Bylaws, version 2.1.0**: records the organization's purpose, governance, membership, leadership, project structure, and operating rules; the document states that it was last updated June 27, 2026.

Two downloaded copies of the MEP proposal were supplied. Their Word document content is identical; only Office package metadata differs. The copy named `DIGITAL_CPP_Project_Proposal_MEP.docx` is retained as the canonical artifact to avoid a misleading duplicate.
